# 选股预测层与推荐界面验收

2026-10-27。第一阶段修复已提交为 `a05a1ce`，本阶段按用户提供的“规则筛选、多因子排名、机器学习、预测置信度校准”继续实现。

## 实现结果

| 功能 | 实现与边界 |
| --- | --- |
| 规则筛选 | 同一行情日期、有效价格、有效成交量、至少 120 个历史交易日、当前名称风险标记；可加成交额、板块、行业及信号日近涨停门槛。返回排除原因，零候选时不使用旧日期补位。 |
| 多因子排名 | 权重和方向仅从训练期中性化因子的每日 Rank IC 得到；展示 0–100 对照分数、因子权重、分位与贡献。与 LightGBM 分数独立，缺失必要输入不填假分数。 |
| 机器学习预测 | 默认使用 LightGBM 原始排序分数，保留训练期内按日期分组调参和成熟标签隔离。持久化样本取消 float32 降精度，防止保存后改变树分支。 |
| 概率校准 | 独立验证区间拟合单调 Platt 校准器，按日期等权；校准器不读取测试标签，不允许负斜率反转模型排序。SHAP 仍解释原始树模型输出。 |
| 推荐界面 | 独立推荐组件；可切换模型/因子排序，展示筛选计数、原始分数、校准概率、因子分数及明细；集成 SHAP、K 线入口，导出当前筛选结果。移动端提供单股摘要。 |
| 诊断图表 | 同图比较校准前后可靠性，Brier 和 ECE 同时列示；保留 Rank IC、平仓月份热力图与 SHAP 依赖图。 |

当前规则作用于最新推荐快照，未把一次页面筛选伪装成重新计算后的历史策略结果。未分类股票另行提示，不能把它们合计占比当作一个真实行业。
