# AUC 0.4985 原因分析与改进验收

完整批次：`20261027-120722-ecde33c1`；旧批次：`20261027-023632-b575a153`。
使用 300 只股票的本地原始缓存，行情至 2026-10-21，成熟标签至 2026-10-14。未将缓存称为实时行情，也未补造缺失数据。

| 指标 | 旧模型 | 新模型 |
| --- | ---: | ---: |
| 训练 AUC | 0.5911 | 0.5389 |
| 验证 AUC | 0.4999 | 0.4975 |
| 测试 AUC | 0.4985 | **0.5153** |

| 测试 Precision@5 | 0.4136 | 0.4654 |

新旧测试严格使用同样的 127,741 个日期/股票键、相同标签，覆盖 2025-01-03 至 2026-10-14 共 428 个截面。训练仍为 483,658 行、1,987 日；验证为 125,031 行、422 日。新增特征不参与样本覆盖率分母，避免通过更换样本制造提升。

测试截面 AUC 改变量为 0.01904，20 日移动块 bootstrap 的条件 95% 区间为 `[0.00315, 0.03704]`。但新模型相对 0.5 的区间为 `[-0.00223, 0.03644]`，验证期也未改善。因此结果支持“本次回顾性复核优于旧模型”，**不支持稳定 alpha、显著优于随机或实盘可盈利的结论**。

原测试期此前已查看，本次不是新的未触碰盲测。协议在最终完整运行计算候选得分前固化；只根据原训练期内部得分选型，外部结果未触发追加方案、参数搜索或概率反转。此前两个开发运行在基础检查阶段停止，未进入外部评价；其部分内部对照得分不作为新增候选。

## 0.4985 的主要原因

1. **模型容量与信号强度不匹配。** 旧学习率约 0.1725、深度 7、41 叶、212 棵树，叶节点最小样本数沿用较小默认值；训练 AUC 0.5911 而验证/测试约 0.5，是明显的泛化差距。仅 5 次宽范围搜索不能证明这些参数稳定。浅树、较大叶样本约束与更强正则化后，训练/测试 AUC 差距由约 0.093 降至 0.024。
2. **筛选与输入表示不一致。** 旧诊断用原始因子 IC，模型却用中性化输入。例如资产负债率的训练期 IC 从原始约 −0.0179 降至中性化后的 −0.0050。现在诊断实际输入，并把单因子门槛与模型实际入模列表分别展示。
3. **单因子筛选限制了模型信息。** 旧模型只用 MACD、资产负债率和 OBV 三因子。固定量价候选使模型能够利用互补和非线性信息；单因子显著性不再是所有方案唯一的入模门槛。
4. **候选数据缺失和重复。** 训练期 ROA、利润增长率缺失率为 100%，不能填零后假装存在。这两个字段本来就没进入旧三因子模型，属于候选信息不足，不能说它们直接污染了旧模型输入。`turnover_proxy` 与稳定期的 `vol_ratio` 基本重复，不重复入模。质量筛选只用每折过去数据，要求总覆盖率至少 90%、每季度至少 70%、足够变异；例如 60 日动量的早期季度覆盖不足，未进入最终 18 维输入。
5. **预测周期与市场状态。** 补充 5/10 日动量、当日开收盘收益、当日隔夜跳空、收盘位置和 20 日非流动性。旧特征偏重较长趋势，对短期截面任务不充分。内部比较支持适度增益，但验证期仍近随机、滚动窗口亦有负面结果，说明非平稳性仍存在。

训练期审计未发现重复日期/股票键或无效 OHLC 行；行业未分类行占约 15.96%。这只说明该审计范围内通过，不能证明全部数据无偏。完整缺失率、原始/中性化 IC 和季度覆盖率见 `auc-evidence/training_data_audit.json`。

## 固定候选比较与防泄漏约束

原训练期末部三个连续的 252 交易日区间作内部验证。每折保留 5 日间隔，并清除 `label_end_date >= 验证起点` 的训练样本；截面、覆盖率和 IC 筛选只用该折训练数据。改进候选按日期等权拟合，以截面 AUC 均值减去 0.25 倍折间标准差选型；外部验证和测试不用于早停。

| 固定方案 | 内部截面 AUC 均值 | 折间标准差 | 选择得分 |
| --- | ---: | ---: | ---: |
| 旧参数与原始 IC 对照 | 0.50621 | 0.00316 | 0.50542 |
| 实际输入 IC + 正则化 | 0.51133 | 0.00844 | 0.50922 |
| 既有量价 + 正则化 | 0.52378 | 0.00636 | 0.52219 |
| **增强量价 + 正则化** | **0.52452** | **0.00435** | **0.52344** |
| 增强量价 + 756 日滚动 | 0.52359 | 0.00748 | 0.52172 |
| 覆盖合格全因子（仅诊断） | 0.52327 | 0.00956 | 0.52088 |
| 增强量价 + 更浅树 | 0.52406 | 0.00510 | 0.52278 |

共 7 个方案，其中旧模型和基本面全因子为对照，5 个可选方案。基本面缓存未提供可核实的真实公告时点及历史修订版本，质量合格不代表时点合规，因此不进入默认方案选择。旧参数本身来自此前训练期搜索，其内部对照得分亦不作为独立无偏确认。

增强量价相对既有量价的内部 AUC 增量仅约 0.00074，不能将总提升都归因于新增六因子。这些是预先固定的组合方案比较，并非严格逐项因果消融。

胜出模型仍是可由 TreeSHAP 精确解释的 LightGBM 二分类模型：200 棵树、学习率 0.025、最大深度 3、最多 7 叶、最小叶样本 500、L1=1、L2=20。最终使用 18 个量价输入。协议、全部候选的逐折日期/特征/得分与 SHA256 保存在 `auc-evidence/model_selection*.json`。全局 SHAP 主要来自 RSI、5 日动量、非流动性、CCI、ATR；这描述模型关联，不是因果效应。SHAP 未用于根据测试结果二次筛选。

方案选择截至 2023-03-23，后续 walk-forward 从 2023-03-31 才开始，不把未来选择的方案套回早期窗口宣称验证。7 个外部窗口平均 AUC 0.5056，中位数 0.5013，3/7 低于随机；此前旧报告的 13 个窗口时间范围不同，不能直接比较两者均值。

## 保留的负面结果与限制

- 同输入本轮基线：逻辑回归 AUC 0.5141、随机森林 0.5171。LightGBM 0.5153 尚未超过随机森林；保留论文主题，同时完整报告基线，不按测试期结果换模型。
- 测试收益排序的平均 Rank IC 约 0.0013、HAC t 约 0.10，仍然很弱。二分类 AUC 改善不等于未来收益排序或收益幅度预测已可靠。
- 验证期校准斜率为 0，校准概率约 46.69%，标记 `weak_validation_signal=true`。测试 Brier 原始 0.24634、校准后 0.24723；ECE 原始 0.00064、校准后 0.02525。校准变差如实保留，不根据测试集改选方法；默认排序继续使用原始模型分数。
- 单次行业中性回测年化 36.48%、相对基准年化 22.16%，但周期估值、固定费用、成交假设及历史股票池均有限制。滚动拼接回测年化 17.22%、最大回撤 −23.27%；alpha 检验 p=0.1619，尚不显著。不能用这些收益数字替代预测与稳健性检验。
- 仍缺历史成分股和完整历史行业分类，存在幸存者偏差；前复权供应商历史修订也可能影响历史特征。此轮未补造时点数据，不能把结果称为完全消除数据偏差的研究。
- bootstrap 仅给出本次固定比较下的条件区间，未修正历次所有隐性试验。未来未观察数据的前瞻确认仍是必要的下一步，而不是继续挖掘旧测试期。

## 验证与复现

完整训练命令（`--reuse-panel` 复用本次刚重建的本地面板，SHA256 记录在批次报告中）：

```powershell
python -m ml_pipeline.run_training --cached --scheme robust --trials 1 --reuse-panel saved_models/runs/20261027-120519-0530393a/processed/panel_dataset.pkl
```

常规从原始缓存重建：`python -m ml_pipeline.run_training --cached --scheme robust --k 10`。`--trials` 只对显式 `legacy` 方案生效。原始缓存、完整面板和模型仍按既有规则保留本地；小型协议与结果证据随代码提交。证据中的 `walk_forward.json` 省略重复交易流水，保留逐窗结果与汇总；完整流水仍在不可变批次中。协议哈希计算不包含发布时追加的 `run_id` 字段，验收脚本据此复核；批次 manifest 另记录完整文件字节哈希。

新增检查覆盖未来截断不变性、样本口径不变、真实标签成熟期隔离、滚动窗口只使用过去、实际输入诊断、日期等权、覆盖率筛选、训练 API 默认方案及变化标签不作虚假配对比较。另验证全部产物哈希、协议哈希、21 个内部折的日期边界、7 个外部窗口边界、300 条推荐分数一致性、校准时段和 TreeSHAP 加和，并检查推荐、训练配置及因子诊断页面。
