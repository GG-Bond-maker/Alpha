# AUC 优化：预先固定的回顾性实验方案

原模型测试 AUC 0.4985，训练 0.5911，验证 0.4999。原测试期已查看，不能再将它称为未触碰盲测。此次只在原训练期内比较方案，冻结胜出方案后一次复核原验证/测试期，不据其结果追加搜索。提交发生在验证完成后，遵从用户要求；运行时在计算任何候选得分前写入协议并记录 SHA256。

候选总数固定为 7（1 个旧方案对照 + 6 个改进方案），完整参数以 model_selection_protocol.json 为准。

1. 旧方案对照：旧高学习率/深树，折内按原始因子 IC 筛选。
2. 中性化 IC：对既有量价因子的实际模型输入诊断，使用浅树与正则化。
3. 既有量价：预先定义的 13 个量价特征，去除重复换手代理。
4. 增强量价：添加 5/10 日动量、当日开收盘收益、当日隔夜跳空、收盘区间位置、20 日非流动性。
5. 增强量价滚动：只用最近 756 个训练交易日。
6. 质量合格全因子：含覆盖率足够的基本面，仅作诊断对照，不参与胜出选择。当前缓存无法核实真实公告时点和历史修订，覆盖率合格不能证明时点合规。
7. 增强量价更浅树：深度 2。

外部验证/测试完全不进入筛选函数。原训练期末部的 3 个连续、各 252 日截面作为内部验证；每折训练均留出 5 日间隔，并清除 label_end_date 尚未早于验证起点的样本。特征覆盖率、去常数和 IC 筛选均只拟合该折训练数据。候选改进方案按日期等权训练，以截面 AUC 均值减去 0.25 倍折间标准差选择，参数/树数不在外部数据上早停。

新增特征不改变原始样本覆盖率门槛与标签；最终旧测试样本和标签必须逐条一致。按日期分块 bootstrap（20 日块，固定种子 42，2000 次）报告改进的条件置信区间。该区间不能纠正过去所有隐性试验或幸存者偏差，不能作为可交易 alpha 的证明。进一步 walk-forward 只能在方案选择结束日期之后开始，避免用未来选出的方案去验证早期窗口。

验收：无训练/验证标签重叠、无未来回填、样本标签一致；真实报告所有候选和外部结果；校准仍仅拟合验证集；TreeSHAP 加和检查、运行时 API 与现有回归测试通过。若效果未提高，保留负面结论，不据旧测试期继续调参。最终仍需未来未观察数据的前瞻确认。
